# Python Learning Journey & Student Performance Analyzer

## Overview

This repository documents my Python learning journey as a beginner. It contains practice programs, exercises created while learning Python fundamentals.

The main project in this repository is a **Student Performance Analyzer**, which demonstrates the use of core Python concepts such as variables, conditional statements, loops, functions, dictionaries, and basic data analysis.

## Contents

### Python Learning Files

A collection of programs created during my first seven days of learning Python, covering topics such as:

* Variables and Data Types
* Input and Output
* Conditional Statements
* Loops
* Functions
* Lists and Dictionaries
* Basic Problem Solving

### Student Performance Analyzer

A console-based Python application that:

* Accepts student names and marks as input
* Calculates total marks
* Calculates average marks
* Assigns grades based on performance
* Identifies the highest-scoring student
* Identifies the lowest-scoring student
* Generates a simple performance report

## Technologies Used

* Python 3
